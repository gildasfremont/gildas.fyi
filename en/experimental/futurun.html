Bringing your accounts together to see how many months of runway you have

An app that runs at home, where reconnecting a bank fits on a single screen

Since October 12, 2026, personal use · Next.js, Python · built with Claude Code · full write-up (Markdown)

As a freelancer, the number that matters is how many months your cash can cover. Getting it means pulling together accounts that don't connect the same way: a bank through open banking, a life insurance savings plan and a retirement savings plan through their customer portals, a statement exported by hand, a loan you enter yourself. Each kind of access expires on its own schedule.

Futurun puts reconnection at the center. The README states the principle: "one connector per source, each with its own method." All connectors follow the same contract, though. Each returns accounts and transactions, and when access expires, raises the "reconnect needed" error, which moves the source to the top of the screen. The method only changes the shape of the form: a username, a key, a file, or a round trip to the bank.

The budget was redone six times on the first day, each time adding a concept: categories, upcoming expenses, actual versus estimated. In the final version, an expense comes down to a name and an amount, with a frequency and a duration if needed.

At home

The app starts with the Mac, syncs every six hours and opens on the phone over the same Wi-Fi. A Docker image also lets you host it elsewhere. Credentials and tokens are encrypted in the data file, and amounts are stored in cents. Eleven connections are active, some fifty tests run, and an MCP server lets you query Futurun from a conversation with Claude.

Updates install from inside the app, with one button.

The latest commits, on October 20, replace personal labels with generic ones and add settings, so that someone else can install it.
