15 au 17 avril 2026 · Rust, Tauri, whisper.cpp · écrit avec Claude Code · code public

Le pari

Le chat est mal fait pour annoter : il faut recopier le passage, attendre la réponse, et tout s'empile dans un fil. Un co-lecteur silencieux, qui reçoit des commentaires dits à voix haute et accrochés au texte, peut le remplacer. Il tourne sur le Mac, avec l'abonnement Claude de l'utilisateur, sans clé d'API.

Genèse

La spécification a été écrite le 15 avril au soir, avec une architecture en Next.js. Le lendemain matin, elle a été réécrite : l'app serait de bureau, en Tauri, avec Whisper en local et Claude appelé en ligne de commande. Raison donnée dans le document : un Mac de 8 Go, pas de clé d'API, pas de serveur. Les cinq tickets de la première feuille de route ont été annulés.

Le projet a aussi servi de terrain pour une méthode : deux agents qui travaillent ensemble sans se parler directement.

Essais et erreurs

  • Bloquant

    La latence

    Les classifications étaient justes et la mémoire tenait, mais chaque appel de Claude en sous-processus coûte plusieurs secondes avant même de réfléchir.

    Haiku, seul5,4 à 11 s Haiku, dans l'app17 s Opus, premier mot11,7 s

    trait vert : la cible · rapport de tests du 17 avril

  • Corrigé

    Un prompt système que personne ne lisait

    Claude a d'abord passé ses consignes par une variable d'environnement que l'outil en ligne de commande ignore. Pendant une dizaine de minutes, le classifieur a répondu comme dans une conversation. La note qu'il en a laissée : toujours lire l'aide de la commande avant de deviner.

  • Remplacé

    Détecter la voix au volume

    La détection par le niveau sonore captait tout, au point que Whisper a fini par transcrire un bruit de porte. Elle a été remplacée par une touche à maintenir pour parler.

  • Signalé

    Le périmètre qui glisse

    Le 17 avril, trois nouvelles idées sont apparues : garder l'historique, versionner, laisser l'IA modifier le texte, trois idées qui sortaient du premier périmètre. Claude Code l'a relevé dans une note qui déclarait l'architecture périmée.

  • Faille

    Un fichier qui ne devait pas être lu

    Cowork gardait ses critères de recette dans un fichier marqué « Claude Code ne doit jamais voir ce fichier ». Un git add trop large a ajouté le fichier au dépôt, où Claude Code l'a lu avant de le retirer. Le dépôt en conclut que la convention est fragile.
